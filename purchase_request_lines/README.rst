This module extends the functionality of Purchase Requests by adding **sequence numbers to each line** in a request.

This helps purchasing teams to:

* Identify each line individually during the procurement process.
* Avoid confusion in large requests, especially in corporate or industrial environments where Purchase Requests might have dozens or even hundreds of lines.
* Refer to lines by sequence number during communication with requesters, approvers, or suppliers.

# **Key Features**

* Auto-numbering of purchase request lines.
* Manual override of sequence if needed (configurable).
* Sorting by sequence in both form and tree views.
* Fully compatible with the OCA `purchase_request` module.

# Usage

\#. Go to *Purchase Requests* and open or create a new request.
\#. Add multiple lines. Each line will receive a unique sequence number.
\#. You can manually adjust the sequence if needed.
\#. The lines will be displayed sorted by their sequence both in the form and list views.
